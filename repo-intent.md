# Repo intent — hyper-v-renaissance

**Assets repository for the "Hyper-V Renaissance" blog series.**

## What this repo is

Scripts, templates, diagrams, checklists, and supporting resources for the "Hyper-V
Renaissance" blog series on thisismydemo.github.io, aimed at IT professionals,
architects, and decision-makers who want production-ready assets alongside each
post.

## Shape

- `01-case-for-change/` through `05-series-wrap-up/` — one folder per post/phase
  in the series, each mapping to a specific blog entry
- `diagrams/`, `references/`

## How it relates to other repos

- Companion to the blog series on **`thisismydemo.github.io`** — read the relevant
  blog post for context on any given folder before using its assets

## Status

Active, content-complete through whatever phase the blog series has reached
(check `05-series-wrap-up/` for series status).
